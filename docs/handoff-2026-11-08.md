## Reproduced failures and fixes

- Explicit `announcementIds` bypassed `llm_quota_pause`. Those IDs now honour the same pause and each row's retry time.
- `batchSize: 1` did not constrain an explicit repair selection: every selected row entered `Promise.all`. Work now runs in bounded waves and stops starting later waves after quota pressure or a deadline.
- OCR discarded HTTP 429/Retry-After and tried all models. A 429 now stops that call and propagates a typed deferred result through both full-document and page-targeted extraction. The worker records an outage and a retry time without consuming document attempts.
- `ocr-quota.service.js` uses an atomic `system_settings` row lease, bounded expiry and owner-checked release. Scanner/repair/failover OCR calls share it. There is a 15-second interval after each OCR job, and persisted escalating cooldowns of 10/30/60/120/180 minutes after 429, extended when the provider requests longer. No worker waits through a long cooldown. External quotas can still cause 429; those failures are deferred safely.
- Targeted OCR remains targeted during forced rereads. Clean statements precede broken embedded text, token-truncated responses are rejected, and the same extraction is not OCR-submitted twice by the worker. OCR instructions preserve millions, and conflicting printed/transcribed units are rejected.
- Historical repairs could substitute static benchmark figures and mark them `THIS_FILING`. Removed this fallback from filing verification. Parsed figures saved on snapshots now identify their source announcement, attachment and OCR provenance.
- A failed snapshot upsert was swallowed, allowing a repair to appear completed. It now fails processing and is retried.
- Importing `backend/db/pool.js` executed a DELETE against `filing_drive_links`, including during audits/dry runs. Removed the import-time mutation.
- Requeue selections exclude flagged foreign filings. Foreign cleanup traces actual string values (including quotes/newlines), includes previously flagged foreign sources, and preserves ambiguous evidence also found in a verified own-company filing.
- Statement-page detection preserves tables with notes beneath them while excluding notes-only introductions.
- Health reporting includes an OCR quota backlog finding.
