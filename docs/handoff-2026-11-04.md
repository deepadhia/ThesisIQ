## Code changes (commit 55df888)
- **Parser** (`financial-validator.service.js`): OCR letters inside numbers repaired only in a decimal-ending token with ≥2 real digits ("197.GO"); tolerant PBT/PAT/finance/depreciation/other-income row labels; owners-row search stops at a "comprehensive income" heading; header dates accepted only if month-ends, current first, and quarter column before year-ago column (scrambled headers fall back to the standard layout); period read from the statement heading (**latest** month-end date named, so a "previous quarter" line nearer the table cannot win); **PAT outside 25–160% of its own PBT is withheld** with `patRejectedReason`, with all growth rates built on it; EBITDA = PBT + finance + depreciation − other income (falls back to the inclusive figure when no other-income row is readable).
- **AI-located fallback** (`financial-table-fallback.service.js`): `other_income` row added so its EBITDA uses the same definition.
- **Digest**: signal + conviction next to the status; block "HOW THIS SIGNAL WAS REACHED" (results with hurdle, driver tally, the filing, concall analysed/pending, one named verdict reason in priority order broken driver → at-risk driver → missed hurdle → unverified numbers); gate result stored compactly on the digest item; near-duplicate bullets merged (`dedupeNearDuplicates`).
- **Results flash** (`buildStage1Message`): signal + "➡️ Why" (from the gate) first, then summary, verified numbers, gate, drivers, pacing, cash quality, valuation, positives, drags, open queries; bullets that only restate verified revenue/PAT/EBITDA are dropped (`dropRestatedFigures`).
- **Workflow**: `scan-announcements.yml` passes `OPENROUTER_API_KEY`.
- **New**: `backend/scripts/audit-stored-financials.js` (read-only; re-parses stored results documents and lists rows holding wrong figures, with the `requeue-stuck-filings.js --ids …` command) and its test.
- **Fixtures** (full real filings): `backend/tests/fixtures/real-layouts/TRANSRAILL_2026-11-03.txt`, `JYOTICNC_2026-11-03.txt`. Nine existing EBITDA expectations changed with the new definition; each re-derived by hand from the printed rows (ELECON 147.90, HSCL 344.96, GRAVITA 133.98, ANANTRAJ 197.95 / +331 bps, SHAKTIPUMP 64.03, two synthetic cases). One guard test's guidance figure moved from 33.5% to 30.5% (the old value only passed because it sat within 1 point of the old inclusive margin). No assertion was removed.
