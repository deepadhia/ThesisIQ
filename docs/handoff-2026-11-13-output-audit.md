### GitHub and Reddit reuse follow-up

- [ShantanuAnant/nse-xbrl](https://github.com/ShantanuAnant/nse-xbrl) is MIT-licensed and maps NSE Integrated Filing XML into ~100 financial fields. It is a useful benchmark/alias source, but its visible tests use one synthetic financial fixture, and its generic parser strips namespace identity and retains facts by local tag/context only. `unitRef`, decimals, dimensions and provenance are not preserved in its flat output; the README itself says values may be in the filer's unit and mappings are incomplete. Do not adopt it as an automatic signal-authorizing truth layer without real multi-company reconciliation tests.

A Windows checkout also failed on very long bundled-taxonomy paths. Architecture is useful, but it is not a drop-in validated financial parser here.

Keep the Indian concept mapping and confidence gates local and test them against official files. [india-xbrl-filings](https://github.com/dhananjaym182/india-xbrl-filings) can inform raw-file manifests/revision handling; it explicitly does not normalize statements.
